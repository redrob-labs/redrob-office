# Sample Redrob Office skills

Shareable `.redrobskill` packages for Discord/Slack attachments. Each file is JSON:

- `workflow` — user flow definition
- `rubrics` — inlined **user** rubrics only (built-in templates/schemas are referenced by id)
- `manifest` — title + one-line description for sharing

Import via **Flows → Import skill** in Desk. Export a saved flow with **Share as skill**.

| File | What it does |
| --- | --- |
| `community-assess-candidates.redrobskill` | Resume intake → 6-axis assess |
| `community-jd-draft.redrobskill` | Draft a job posting |
