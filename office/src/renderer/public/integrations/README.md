# Integration logos

These files are static copies of the published brand marks, not React-drawn
approximations. They are used only to identify the corresponding MCP
integration.

The SVG files were retrieved from Iconify's `logos` collection. Review and
refresh them against each vendor's current brand resources before changing
their geometry or colors:

- Figma: https://www.figma.com/using-the-figma-brand/
- GitHub: https://github.com/logos
- Brave: https://brave.com/brave-branding-assets/
- PostgreSQL: https://wiki.postgresql.org/wiki/Logo
- Notion: https://www.notion.so
- Google Chrome: https://www.google.com/permissions/
- Slack: https://slack.com/media-kit
- Discord: https://discord.com/branding
- WhatsApp: https://www.meta.com/brand/resources/whatsapp/whatsapp-brand/

All marks remain trademarks of their respective owners.
