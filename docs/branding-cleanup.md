# Branding: Redrob Office

The multi-editor office suite (`apps/shell` + `apps/docs`, `apps/sheets`,
`apps/slides`, `apps/pdf`, `apps/markdown`, `apps/hangul`) is **Redrob Office**.
Every user-visible surface uses Redrob branding and the official Redrob logo
assets. Some internal, load-bearing identifiers keep their `GenOffice` /
`Genspark` names because renaming them would break files, data, packages, or the
ported cloud endpoints. This document is the single source of truth for what is
user-facing (must be Redrob) versus what is an allowed internal exception. The
static audit test (`apps/shell/tests/branding-audit.test.ts`) enforces it.

## Product names

- Suite: **Redrob Office**. Window title: `Redrob`.
- Editors: **Redrob Docs / Sheets / Slides / PDF / Markdown / Hangul**.
- AI: **Redrob AI** (the single Redrob engine / Redrob Console). There is no
  provider picker and no BYOK vendor choice.
- No em dash (`—`) in user-facing copy.

## Logo assets

The official Redrob assets live under `office/src/renderer/public/` (`logo.svg`,
`logo-on-dark.svg`, `logo-long.svg`) and `office/build/icon.svg`, generated by
`office/scripts/render-icons.mjs` from one mark definition. The shell reuses
copies of these:

- Sidebar wordmark: `apps/shell/src/renderer/src/assets/redrob-logo.svg` (dark
  text, for light theme) and `redrob-logo-on-dark.svg` (light text, for dark
  theme). CSS in `home.css` shows one per theme, so the colored gradient mark is
  never run through a CSS `invert()`.
- Onboarding + update window: `redrob-mark.svg` (mark on a white tile) and
  `redrob-mark-on-dark.svg` (mark on the brand navy tile), swapped by theme.
- App / build icons: `apps/shell/build/` and `apps/docs/build/` `icon.png`,
  `icon.ico`, `icon.svg`, `icon-mac.png` are the official Redrob icon.
- Per-file-type document icons (`docx`, `xlsx`, `pptx`, `pdf`, `md` `.icns` /
  `.ico`) are intentionally left as-is: they are document-type glyphs, not the
  product brand.
- `GensparkMark` (the inline AI-panel badge component) keeps its identifier to
  avoid churn across many call sites, but its artwork is now the Redrob mark.

## Allowed internal exceptions (NOT user-facing; do not rename)

Renaming any of these would break something concrete, so they keep the legacy
token. The audit test allowlists them by exact file/value.

1. **`@genoffice/*` workspace package names** and `tsconfig.genoffice.base.json`.
   Hundreds of imports and workspace refs resolve by these names; Apache-2.0
   requires only the product *name* to change, not internal identifiers.
2. **`@genoffice/shell` package name** (dev/test harness, not display copy). The
   dev-profile userData directory was renamed from `GenOffice Dev` to
   **`Redrob Office Dev`** (with a one-time non-destructive migration; see
   `apps/shell/src/main/userdata-migration.ts`), so `GenOffice Dev` is no longer
   used. Only the `GENOFFICE_USER_DATA` env-var NAME is kept, purely for
   compatibility with existing test drivers / CI that set it; it is not shown to
   users.
3. **Font family names and files**: `GenOffice Sans KR`, `GenOffice Serif KR`,
   `GenOffice Gothic KR`, `GenOffice Poppins`, `GenOffice Songti SC`,
   `GenOffice Hiragino …`, `GenOffice Box Drawing`, `GenOffice PUA Blank`,
   `GenOffice Grid Strut`, etc., and the `GenOffice*-*.woff2` files. These are
   font-family identifiers baked into the metrics/CSS pipeline and locked by
   `apps/docs/tests/{kr-font-metrics,line-metrics,fonts-css-contract,...}.test.ts`.
4. **Serialized PDF metadata keys**: `GenOfficeStaticFormFills`,
   `GenOfficeFormField`, the renderer field `genOfficeFormField`, and
   `VISUAL_SIGNATURE_CONTENT_PREFIX = 'GenOffice visual signature field: '`.
   These persist inside saved PDFs and are read back to recover form-field data,
   so renaming would break round-tripping of existing files. (The `/T`
   annotation *author* default is user-visible and WAS changed to
   `Redrob Office`.)
5. **Updater feed plumbing**: `GENOFFICE_UPDATE_URL`, `GENOFFICE_FAKE_UPDATE`
   env vars and the `genspark-ai/genoffice` release-lineage URL used only in test
   fixtures. (The user-facing manual-download page was pointed at
   `redrob-labs/redrob-office`.)
6. **Ported Genspark cloud endpoints and identifiers**: `GENSPARK_ORIGIN`,
   `CREDIT_USAGE_URL`, `resolveProxy('https://www.genspark.ai/')`,
   `GenSparkAccountStatus`, and the `gsk` / `gsk login` CLI command names, plus
   the code comments that describe those real hosts. These are the actual
   upstream cloud service the ported login / cloud-projects / proxy code talks
   to; the token is kept so the comments stay accurate. Their user-facing copy
   (labels, dialogs, credit-exhausted messages) was rebranded to Redrob and the
   top-up URL repointed to `console.redrob.ai`.
7. **Univer command IDs** (`genoffice.command.*`), the `genofficeAnalytics`
   package key, the `GenOfficeCrossHighlightExtension` Univer extension key, and
   test fixtures (`<Application>GenOffice Fixture</Application>`, docx-export /
   commands / image-skill test literals). Serialized identifiers and test data.
8. **Upstream Apache-2.0 attribution** in `NOTICE` (Mainfunc, Inc.). Required by
   Apache-2.0 section 4; never removed.

## The audit test

`apps/shell/tests/branding-audit.test.ts` scans the source tree for user-visible
`GenOffice` / `Genspark` literals (JSX text, `aria-label` / `title` /
`placeholder` attributes, HTML `<title>`, and i18n string *values*) and fails if
any appear outside the allowlist above. It skips `out/` / `dist/` build
artifacts, `node_modules`, test files, and the documented internal categories.
